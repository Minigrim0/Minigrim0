# Minigrim0

Personal static site for [minigrim0.xyz](https://minigrim0.xyz), built with Astro and deployed to GitHub Pages.

## Develop

```sh
npm install
npm run dev
```

## Content

- CV: `src/content/cv/profile.md`
- Projects: one Markdown file per project in `src/content/projects/`
- Blog posts: Markdown files in `src/content/blog/`

The Blog and RSS navigation only appear after at least one non-draft post exists. Use `src/content/blog/draft-template.md` as a copyable starting point.
